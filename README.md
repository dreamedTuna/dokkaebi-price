# 도깨비의 세계 · 영웅장비 분해 시세표 (앱 버전 1.4.0)

거래소 시세로 **요혼석을 어디서 구하는 게 제일 싼지**, **영웅장비를 사서 분해하면 남는지**를 계산하는 시세표예요.
폰·PC에 앱으로 설치할 수 있고, 인터넷이 끊겨도 열리며, 새 버전을 올리면 사용자 화면에 업데이트 알림이 떠요.
**🗗 미니 창**을 누르면 PC 크롬·엣지에서는 게임 위에 항상 떠 있는 작은 창(크기·위치 자유)으로, 폰에서는 페이지 안에 옮길 수 있는 작은 창으로 시세와 빠른 이득 계산을 볼 수 있어요.

## 폴더 구성

| 파일 | 역할 | 수정 |
|---|---|---|
| `config.js` | **분해량·환산 기준·신호 기준·버전** | ✏️ 관리자만 여기서 수정 |
| `version.json` | 업데이트 알림용 버전 번호 | ✏️ config.js와 같은 번호로 |
| `index.html` | 화면 | 수정할 일 없음 |
| `app.js` | 계산·스크린샷 읽기 (압축된 코드) | 수정할 일 없음 |
| `sw.js` | 오프라인 실행·업데이트 | 수정할 일 없음 |
| `manifest.webmanifest`, `icons/` | 앱 이름·아이콘·부위 아이콘 | 수정할 일 없음 |
| `img/` | 사용법의 스크린샷 예시 | 수정할 일 없음 |
| `vendor/` | 글꼴·글자 인식 도구 (라이선스 파일 포함, 지우지 마세요) | 수정할 일 없음 |
| `내PC에서_실행_*.command / .bat` | 내 컴퓨터에서만 쓸 때 | — |

사용자 화면에는 분해량·환산 기준을 바꾸는 칸이 없어요. **숫자는 관리자가 `config.js`로만** 바꿀 수 있어요.

## 1. 인터넷에 올리기 (GitHub Pages, 무료)

1. [github.com](https://github.com) 가입 → **+ → New repository** → 이름 예: `dokkaebi-price` → **Public** → Create
2. **uploading an existing file** → 이 폴더 안의 **파일과 폴더를 전부** 끌어다 놓기 → **Commit changes**
3. **Settings → Pages** → Source: **Deploy from a branch** / Branch: **main, (root)** → Save
4. 1~2분 뒤 뜨는 주소(예: `https://내아이디.github.io/dokkaebi-price/`)를 길드원에게 공유하세요.

## 1-1. 건의하기 켜기

앱의 **💬 건의하기**는 저장소의 Issues(건의 게시판)로 연결돼요.
- 저장소 **Settings → General → Features → Issues** 체크
- 길드원이 보낸 건의는 저장소 위쪽 **Issues** 탭에서 보고 답할 수 있어요. 처리한 건 **Close issue**로 닫으면 돼요.
- GitHub 계정이 없는 사람도 받고 싶다면 구글 설문지를 만들고, `config.js`의 `feedbackUrl`을 설문지 주소로 바꾸면 돼요. 이때 앱은 적은 내용을 복사해 둔 뒤 설문지를 열어요.

## 2. 나만 수정할 수 있게 지키기 (꼭 해 주세요)

GitHub 저장소는 **기본적으로 만든 사람만 수정**할 수 있어요. 다른 사람은 보기만 하고, 복사해 가더라도 내 사이트는 바꿀 수 없어요. 아래만 지키면 돼요.

- **2단계 인증 켜기**: 오른쪽 위 프로필 → Settings → **Password and authentication → Two-factor authentication** 켜기. 비밀번호가 새도 계정을 지켜줘요.
- **공동 작업자(Collaborators) 추가하지 않기**: 저장소 Settings → Collaborators에 아무도 없어야 해요.
- **실수 방지(선택)**: 저장소 Settings → **Rules → Rulesets → New branch ruleset** → 대상 `main` → ‘Restrict deletions’, ‘Block force pushes’ 체크 → Save. 실수로 지우거나 덮어쓰는 걸 막아줘요.
- 비밀번호·계좌·개인정보 같은 건 **어떤 파일에도 넣지 마세요.** 공개 저장소의 파일은 누구나 볼 수 있어요. (지금 파일에는 개인 정보가 전혀 없어요.)
- 다른 사람이 보내준 파일로 교체하지 말고, 받은 업데이트 파일만 올리세요.

## 3. 설치하기

- **PC(크롬·엣지)**: 맨 위 **📲 앱 설치** 버튼, 또는 주소창 오른쪽 설치 아이콘
- **안드로이드(크롬)**: **📲 앱 설치** 또는 메뉴 ⋮ → ‘앱 설치 / 홈 화면에 추가’
- **아이폰(사파리)**: 공유 버튼 → **홈 화면에 추가**

내 컴퓨터에서만 쓸 때는 `내PC에서_실행_mac.command`(맥) / `내PC에서_실행_windows.bat`(윈도우, 파이썬 필요)을 더블클릭하세요.

## 4. 업데이트하기 (관리자)

1. 숫자만 바뀌면 `config.js`를 열어 해당 값을 고쳐요. 화면·기능이 바뀌는 업데이트는 새로 받은 파일로 교체해요.
2. `config.js`의 `version`과 `version.json`의 `version`을 **같은 숫자로** 올려요. (예: `1.1.0` → `1.1.1`, `notes`에 바뀐 내용 한 줄)
3. GitHub 저장소에 바뀐 파일을 같은 이름으로 다시 올려요 → Commit.

사용자가 앱을 열면(또는 30분마다) 화면 맨 위에 ‘새 버전이 나왔어요’가 뜨고, **지금 업데이트**를 누르면 최신으로 바뀌어요. 각자의 시세 기록은 그대로 남아요.

## 5. 안전하게 만든 부분

- **외부 서버에서 코드를 받지 않아요.** 글꼴과 글자 인식 도구까지 전부 앱 폴더 안에 들어 있고, 보안 정책(CSP)으로 앱 주소 밖의 스크립트·통신을 막아뒀어요.
- **스크린샷과 기록은 기기 밖으로 나가지 않아요.** 글자 인식은 기기 안에서만 하고, 기록은 각자 브라우저에만 저장돼요.
- 저장된 기록을 불러올 때 숫자가 아닌 값·이상한 값은 걸러내요. 읽은 아이템 이름은 화면에 글자로만 표시돼서 코드로 실행되지 않아요.
- 사용자 화면에서는 분해량·환산 기준을 바꿀 수 없어요. 예전에 바꿔둔 값이 남아 있어도 무시하고 항상 `config.js` 값을 써요.
- 개인 정보, 작성자 정보, 개발용 메모는 파일에 넣지 않았어요.
